Privacy

Captain Guild runs on a machine controlled by the people who run the server you're in. This copy serves only its owner's own Discord servers. This page says what it keeps, for how long, and who can see it.

You sign in with Discord. The site asks Discord only who you are, then revokes the token right away and never stores it. The bot's /dashboard command also answers with a private sign-in link, which works once and expires after five minutes. No IP addresses are stored.

Who can see it

Staff of the server the data belongs to, through the dashboard and the log channels they set up, and the person who runs the machine. It isn't sold, shared with anyone else, or used to train machine learning models.

What goes to other services

A lookup sends what you typed to the service that answers it. /games fortnite sends the player's name and platform to Fortnite-API, and /games roblox sends the user name to Roblox. A translation sends the text to DeepL, whether it comes from /translate, the Translate menu, a flag reaction or a message that starts with translate. In a server with Wiki answers on, a request, or a new forum post's title and first message, goes to Anthropic's API with passages from the server's wiki copies, and /ask has it search the web too. The full list of outside services is in the project's THIRD_PARTY.md.

How it's protected

The databases and their scheduled copies are encrypted at rest with SQLCipher (AES-256). The key is held apart from them. The site forces HTTPS.

Getting your data removed

Type /my_data in Discord. The private link opens a page that shows what the bot holds about you, gives you a copy, and deletes your birthday, highlights, reminders, levels, giveaway entries, game scores, usage counts, message counts for voice access and translation language. For anything else, open a ticket with the server's staff or contact the person who runs the bot. Moderation records stay when staff need them to keep the server safe, and stored messages and log entries stay until their retention ends.

Changes

This page changes when the bot's handling of data changes. The history is in the project's public source.
